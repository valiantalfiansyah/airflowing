# How to initalize the airflow project?
1. Download the compose yaml with default configuration
curl -LfO 'https://airflow.apache.org/docs/apache-airflow/3.4.0/docker-compose.yaml'

2. Create the necessary folders for docker such as `dags`, `logs`, `config`, `plugins`. Also adding custom folder such as `tests`, `pipelines`, and `dbt`

3. Create .env and .env.example

4. What values should be stored in .env?
- AIRFLOW_UID: is mainly about file permissions when running Airflow in Docker. We fill it with 1000 for now, same as my current account using `id -u`
- POSTGRES_USER, POSTGRES_PASSWORD, POSTGRES_PASSWORD: Sensitive information of database connection
- FERNET_KEY: Used for encription. Generate it using based 64 url-safe.
```
from cryptography.fernet import Fernet
print(Fernet.generate_key().decode()) ## need to be decoded since generate key resulting bytes.
```
- JWT_SECRET: Used for API token communication between scheduler and worker. Random, we can use hex or base64.
```
import secrets
print(secrets.token_urlsafe(32))
```

5. sudo docker compose up -d

6. Airflow.cfg is auto generated by airflow and should not committed to the repo.
